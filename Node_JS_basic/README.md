# Node JS Basics

Projet Node.js couvrant les fondamentaux : stdin, modules, fs, HTTP natif, Express.

## Fichiers

| Fichier | Description |
|---------|-------------|
| `0-console.js` | displayMessage — stdout |
| `1-stdin.js` | Lecture stdin avec process |
| `2-read_file.js` | Lecture CSV synchrone |
| `3-read_file_async.js` | Lecture CSV asynchrone (Promise) |
| `4-http.js` | Serveur HTTP natif simple |
| `5-http.js` | Serveur HTTP natif + routes |
| `6-http_express.js` | Serveur Express simple |
| `7-http_express.js` | Serveur Express + routes |
| `full_server/` | Serveur Express structuré (ES6) |

## Lancer les tests

```bash
npm install
npm run test
npm run full-test
```
